# Weekly reports

How the Friday report to the supervisor is written, for whoever writes it. Rules use the prefix `WEEK`; its file name follows DOC-50, and its language DOC-26.

## Rules

| ID | Rule | Check |
|---|---|---|
| WEEK-01 | A report MUST follow the template below, the four parts that the product requirements set for weekly reports. | Review |
| WEEK-02 | A report MUST cover only work of its week that is committed or measured, and MUST NOT overstate it. | Review |
| WEEK-03 | Every result MUST give the measured number next to the predicted one. | Review |
| WEEK-04 | Every decision MUST link its ADR, and every failure its incident. | Review |
| WEEK-05 | The last part MUST say which work the author did alone and which with AI help, in words the author chooses. | Review |
| WEEK-06 | A report MUST read as a student writing to the supervisor, not as a translation from English. | Review |

## Template

```markdown
# Báo cáo tuần: YYYY-MM-DD

## 1. Dự đoán và làm hỏng điều gì

<Dự đoán viết trước khi chạy, và cách làm hỏng hệ thống để kiểm tra nó.>

## 2. Kết quả thực tế

<Số đo được, đặt cạnh số đã dự đoán.>

## 3. Quyết định và đánh đổi

<Mỗi quyết định trong tuần, kèm link ADR và cái giá phải trả.>

## 4. Tuần sau

<Việc tuần sau, và phần nào tự làm, phần nào nhờ AI.>
```
